# HWD Schule – Lernkompendium

Statische, deutschsprachige Lernwebsite für das HWD-VWL/BWL-Kompendium. Die Startseite liegt in `index.html` und kann mit GitHub Pages veröffentlicht werden.

## GitHub Pages aktivieren

1. Öffne das Repository **Settings** → **Pages**.
2. Unter **Build and deployment** bei **Source** die Option **Deploy from a branch** auswählen.
3. Als Branch **main** und als Ordner **/(root)** wählen, dann **Save** klicken.
4. Warte, bis der Pages-Workflow abgeschlossen ist. Die öffentliche Website-Adresse erscheint anschließend in **Settings → Pages**.

Das Repository ist öffentlich. Prüfe deshalb, dass du keine privaten oder vertraulichen Inhalte hinzufügst. Die Lerninhalte in der Website sind eine kompakte Zusammenfassung und sollten mit den offiziellen Kursunterlagen abgeglichen werden.
